# ISDATETIME DAX Function (Information)

Checks whether a value is a Date/time, and returns TRUE or FALSE.

## Syntax

ISDATETIME ( <Value> )

| Parameter | Attributes | Description |
| --- | --- | --- |
| Value |  | The value you want to test. |

## Return values

Scalar A single [boolean](https://dax.guide/dt/boolean/) value.

Returns TRUE if the value is date/time.
