# HASH DAX Function

Compute hash over a variable number of input expressions and return a value.

## Syntax

HASH ( <Expression> [, <Expression> [, … ] ] )

| Parameter | Attributes | Description |
| --- | --- | --- |
| Expression | Repeatable | The expression(s) for which the hash is computed. |

## Remarks

The HASH function is not documented by Microsoft yet, but it appears in the Microsoft metadata.
