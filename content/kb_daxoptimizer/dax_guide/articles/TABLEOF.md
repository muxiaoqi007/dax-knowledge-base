# TABLEOF DAX Function (Information)

Returns the table that the specified column, measure, or calendar belongs to.

## Syntax

TABLEOF ( <Reference> )

| Parameter | Attributes | Description |
| --- | --- | --- |
| Reference |  | A column, measure, or calendar reference whose base table is returned. |

## Return values

Table An entire table or a table with one or more columns.

The table that contains the column, measure, or calendar passed as a parameter.
