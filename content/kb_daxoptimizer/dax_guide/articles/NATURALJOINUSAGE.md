# NATURALJOINUSAGE DAX Function (Table manipulation)

Adds a table as Natural Join into filter context.

## Syntax

NATURALJOINUSAGE ( <Expression> )

| Parameter | Attributes | Description |
| --- | --- | --- |
| Expression |  | The table expression to be added to filter context. |

## Remarks

NATURALJOINUSAGE can only be used as a value filter of [[SUMMARIZECOLUMNS]].  
It is intended to be used mainly internally in query sent to other semantic models in composite models.
