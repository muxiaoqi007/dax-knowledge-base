# ISDOUBLE DAX Function (Information)

Checks whether a value is a floating-point decimal number, and returns TRUE or FALSE.

## Syntax

ISDOUBLE ( <Value> )

| Parameter | Attributes | Description |
| --- | --- | --- |
| Value |  | The value you want to test. |

## Return values

Scalar A single [boolean](https://dax.guide/dt/boolean/) value.

Returns TRUE if the value is a floating point decimal number (double).
