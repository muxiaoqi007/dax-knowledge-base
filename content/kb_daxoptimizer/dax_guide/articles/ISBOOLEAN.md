# ISBOOLEAN DAX Function (Information)

Checks whether a value is a boolean value (TRUE or FALSE), and returns TRUE or FALSE. This is an alias of [[ISLOGICAL]].

## Syntax

ISBOOLEAN ( <Value> )

| Parameter | Attributes | Description |
| --- | --- | --- |
| Value |  | The value you want to test. |

## Return values

Scalar A single [boolean](https://dax.guide/dt/boolean/) value.

Returns TRUE if the value is boolean.
